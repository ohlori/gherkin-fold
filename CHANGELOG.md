# Changelog

## 1.0.2

- Make automatic collapse-on-open opt-in and disabled by default.

## 1.0.1

- Replace development documentation with a Cursor-focused usage guide.
- Improve Marketplace discovery for Gherkin folding and scenario collapsing
  searches.

## 1.0.0

- Publish the first stable release of Gherkin Fold.
- Document installation, commands, toolbar visibility, settings, development,
  and VSIX packaging.

## 0.3.1

- Pin the Scenario expand/collapse buttons by default in Cursor and prioritize
  them ahead of editor-title overflow.

## 0.3.0

- Preserve manually expanded Scenarios for the lifetime of an open document.
- Add editor-title buttons to expand or collapse all Scenarios.
- Prevent stale automatic folding from overriding a newer toolbar action.

## 0.1.0

- Detect Scenario, Scenario Outline, and Scenario Template folding regions.
- Collapse scenario ranges once when a `.feature` editor opens.
- Add a command to fold every scenario on demand.
- Add a setting to disable automatic folding.
